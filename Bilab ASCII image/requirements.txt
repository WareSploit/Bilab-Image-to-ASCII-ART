Подготовка окружения
Убедитесь, что у вас установлен Python версии 3.6 или выше.
Откройте папку проекта в Visual Studio Code.
Откройте терминал (Ctrl + `) и установите зависимости командой:
pip install pillow numpy opencv-python
Структура файлов
В корневой папке проекта должна находиться папка с названием assets.
Поместите ваше изображение (например, AnimeGirl.png) внутрь папки assets.
Поддерживаемые форматы: .png, .jpg, .jpeg, .webp.
Запуск через интерфейс VS Code
В левой панели проводника найдите папку bilab.
Откройте файл main.py внутри этой папки.
Нажмите кнопку "Run Python File" (зеленый треугольник) в правом верхнем углу редактора.
Результат отобразится в нижней панели терминала.
Профессиональный запуск (через консоль)
Чтобы проект работал как полноценная программа, установите его в режиме разработки.
В терминале выполните команду:
pip install -e .
После установки вы можете запустить конвертер из любой строки терминала командой:
python -m bilab.main
Настройка качества
Откройте файл bilab/main.py.
Найдите строку вызова функции convert_to_ascii.
Измените параметр height=50 на нужное вам число строк (например, 30 для маленькой картинки или 80 для детальной).
Сохраните файл и запустите проект заново.
Возможные проблемы
Если появляется ошибка "Image not found", проверьте, что файл действительно лежит в папке assets и его имя написано без ошибок.
Если картинка выглядит сплющенной, убедитесь, что в вашем терминале используется моноширинный шрифт (например, Consolas или Fira Code).
